# Snap flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Camera through Sia's eye and a minimal Review where the meal fills today's eye ring.

**Architecture:** Pure maths in `utils/reviewMath.ts`; `CalorieEyeRing` learns a "before" arc and custom centre text; `SiaPeek` accepts a local `reaction` so Review and Camera drive her without the global store; Camera and Review screens are rebuilt around those pieces, keeping all existing logic.

**Tech Stack:** Expo SDK 58, expo-camera, react-native-svg 15, Reanimated 4, zustand 5, Jest + RNTL 14.

**Spec:** `docs/superpowers/specs/2026-11-19-snap-flow-design.md`

## Global Constraints
- No raw hex in `src/app/**` / `src/components/**`; tokens from `src/theme`.
- Text ≥ 12 pt, targets ≥ 44 × 44, contrast 4.5:1 text / 3:1 UI; plain words, no puns outside Sia's lines.
- Animate transform/opacity/SVG props only; static under reduced motion.
- No conditional `active:`/`focus:`/`animate-`/`transition` classes (guard test).
- Every task: `npx tsc --noEmit` clean, `npx jest` green; Co-Authored-By trailer.

## Review Focus
- Today has no meals / no target: ring shows only the green slice; "after" line still correct (Task 1).
- Portion 0.5× of an odd number rounds sensibly and "after" updates (Task 1).
- Meal + today already over target: arc amber, "N over after", never negative "left" (Task 1).
- Editing exact numbers then changing portion: portion scales from the AI's numbers, not edited ones (Task 3, documented choice).
- Camera permission denied / barcode not found: plain messages, no red box (Task 4).
